# BV-Sallaj Boden & Innenausbau – Website

Statische, dreisprachige Website (DE / EN / SQ) – ohne Build-Schritt.

- `index.html` – Startseite
- `impressum.html` – Impressum (Angaben in [Klammern] ergänzen!)
- `css/styles.css` – Design
- `js/i18n.js` – Übersetzungen
- `js/main.js` – Sprachumschaltung, Menü, Animationen, Kontaktformular

Lokal ansehen: `index.html` im Browser öffnen.
Das Kontaktformular nutzt Netlify Forms (funktioniert nach Deployment auf Netlify).
